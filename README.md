# Mekanism → Fabric

Unofficial Fabric port of [Mekanism](https://github.com/mekanism/Mekanism) (MIT, code and assets).

## Why
- ~182M downloads, NeoForge-only. No Fabric port has ever shipped (upstream PR #8598 was closed).
- License: MIT for the whole repo, so redistribution is allowed with the copyright notice kept.

## Version roadmap
1. **1.21.1**, ported from upstream release `10.7.19` (branch `1.21.x`). Current target.
2. 26.2 (upstream branch `26.2`)
3. 26.1.2 (upstream branch `26.1`)
4. 26.3 (upstream branch `26.3`)

## Layout
- `upstream/`: clone of the official Mekanism repo (reference only, not edited)
- `port/`: the Fabric port project
- `NOTES.md`: porting log, API mapping decisions, and known gaps
